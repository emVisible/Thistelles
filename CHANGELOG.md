Changelog

## [0.1.0] - 2026-07-24

### Added

- macOS menu bar voice input via `rumps`
- Global hotkey `⌘⇧I` to toggle recording
- Local transcription via `faster-whisper` (Base / Max modes)
- Clipboard copy on transcription complete
- Waveform overlay with 32 bezier-curve thorns
- Full i18n (zh-CN / en-US)
- History tracking with configurable limit
- Config file at `~/.voice-input/config.json`
- `guide.sh` interactive installer / uninstaller
- Programmatic NSImage icon generation
