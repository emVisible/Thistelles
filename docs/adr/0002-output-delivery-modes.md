# ADR-0002 · 转写结果投递：三分法输出模式

状态：已采纳 · 日期：2026-08-22

## 背景

转写完成后如何交付文本存在三种用户预期：

1. 竞品主流（Wispr Flow / Superwhisper）：直接落在光标处
2. 传统听写工具：复制到剪贴板，用户手动 ⌘V
3. 混合需求：既粘贴又希望剪贴板保留文本以便二次使用

光标插入的机制约束：macOS 无跨应用"写入焦点控件"的可靠 API，
业界通行做法是「写剪贴板 → 合成 ⌘V 键击 → 延迟还原原剪贴板」，
依赖辅助功能权限且对响应慢的目标应用存在竞态。

## 决策

`output_mode` 三选一，粘贴动作必须先经模式门禁再执行：

| 模式 | 行为 |
|------|------|
| `paste`（默认） | 写剪贴板 → ⌘V → 0.6s 后还原原剪贴板 |
| `both` | 写剪贴板 → ⌘V，文本保留在剪贴板 |
| `clipboard` | 仅写剪贴板，绝不触发 CGEvent |

无辅助功能权限时自动降级为 `clipboard` 并照常通知，不丢文本。

## 结果

- 曾出现回归：粘贴调用写在模式分支之前导致 clipboard 模式也会粘贴——
  已由单元测试锁定三种模式的触发矩阵（tests/test_inserter.py），防复发。
